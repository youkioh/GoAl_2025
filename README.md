# Brief

This is the MTRA code on Linux gcc environment.

MTRA/run_MTRA.sh is a script to run MTRA.

VERBOSE MACRO in simulator.h is used to print the log of MTRA (given in original source code).
DRONE_PATH_VISUALIZATION MACRO in simulator.h is used to visualize the path of drones in MTRA (made for drone path visualization by Sungsu).
